# Xbox Cloud Community Landing Page

Projeto criado com React, TypeScript, Vite e Tailwind CSS baseado em um design de landing page Xbox Cloud.

## Scripts

- `npm install` - instala dependências
- `npm run dev` - inicia servidor de desenvolvimento
- `npm run build` - compila o projeto para produção
- `npm run lint` - executa ESLint
- `npm run format` - formata todos os arquivos com Prettier

## Estrutura

- `src/` - código fonte do aplicativo
- `src/pages/` - páginas com rotas
- `src/components/` - componentes reutilizáveis
- `.env` / `.env.local` - variáveis de ambiente para configuração

## Variáveis de ambiente

- `VITE_APP_TITLE` - título do aplicativo
- `VITE_API_BASE_URL` - base URL para chamadas de API simuladas
- `VITE_APP_ENV` - ambiente de desenvolvimento

## Observações

A página é uma landing page de exemplo com navegação, sessão de destaque, categorias e cards de favoritos inspirados no design Figma.
